# Phyr Studios – Internship Assessment Demo

This is a **demo/practice project template** for demonstrating a data-analysis workflow using Python, SQL, Excel, Tableau and Power BI.

## Workflow
Raw CSV → Data Cleaning → Python Analysis → SQL Analysis → Dashboard → Insights

## Files
- `data/sales_raw.csv` – raw dataset with intentional data-quality issues
- `data/sales_cleaned.csv` – cleaned dataset
- `analysis.py` – cleaning, KPIs, analysis and charts
- `sql/analysis_queries.sql` – SQL analysis queries
- `requirements.txt` – Python dependencies
- `output/` – generated charts

## Run
Open this folder in VS Code, then in Terminal:

```bash
pip install -r requirements.txt
python analysis.py
```

Then import `data/sales_cleaned.csv` into Power BI or Tableau.

**Important:** Use this as a practice/demo artifact unless it accurately represents the work you actually performed during your internship.
