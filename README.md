# Phyr Studios – Sales Data Analysis

## About the Project

A sales data analysis project focused on cleaning raw data, analysing sales performance, and identifying useful insights using Python and SQL. The analysis can also be used to build dashboards in Power BI or Tableau.

## Workflow

Raw Data → Data Cleaning → Data Analysis → SQL Queries → Visualization → Insights

## Tech Stack

* **Python (Pandas, NumPy, Matplotlib)** – Data cleaning, analysis and charts
* **SQL** – Querying data and analysing sales trends
* **Excel** – Working with tabular data
* **Power BI & Tableau** – Data visualization and dashboards

## Key Highlights

* Cleaned the raw dataset and handled data quality issues.
* Calculated key sales metrics and KPIs.
* Used SQL queries to analyse sales performance.
* Created charts to present the analysis.
* Prepared the cleaned dataset for dashboard visualization.
